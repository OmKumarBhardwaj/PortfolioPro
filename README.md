# PortfolioPro — a Stock Portfolio Analyzer

Core logic for analyzing stock portfolios, designed to support multiple stock-quote providers behind one interface and published as a reusable library.

## Features
- Portfolio analysis core with clean refactoring history
- Pluggable stock-quote provider support
- Robust exception handling and unit tests

## Tech stack
Java · REST · Jackson · Gradle · Design Patterns

## Context
Built as part of [Crio.Do](https://www.crio.do/)'s project-based curriculum (2022–23) — one of a series of backend projects; see the full portfolio at [github.com/OmKumarBhardwaj](https://github.com/OmKumarBhardwaj).
